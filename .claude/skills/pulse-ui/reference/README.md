# Capturas de referencia

Pon aquí capturas (PNG) de las pantallas objetivo. Cuando construyas una pantalla, pide a la IA que replique la captura usando los tokens de ../tokens y las reglas de ../DESIGN-SPEC.md.

Para capturarlas al píxel desde un emulador Android:

```
adb exec-out screencap -p > reference/overview.png
```
